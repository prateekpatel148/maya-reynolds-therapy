# Dr. Maya Reynolds Therapy Website

A redesigned therapy practice homepage for the Grow My Therapy Front-End Developer Internship assignment.

## Stack
- Next.js 15
- React 19
- Tailwind CSS 4
- Lucide React

## Design direction
The page preserves the reference site's editorial, spacious homepage structure while introducing a clearly different visual identity for Dr. Maya Reynolds:

- Deep Plum: `#4A2947`
- Plum Deep: `#321D31`
- Dusty Rose: `#B87887`
- Soft Blush: `#F4E6E9`
- Warm Ochre: `#C59A56`
- Cream: `#FBF7F2`

The theme is intentionally warm, calm, premium, and therapy-focused.

## Included sections
1. Sticky-style transparent navigation
2. Hero section
3. About / introductory copy
4. Who I Work With
5. Areas of Expertise
6. How I Work
7. Three specialties
8. Dr. Maya Reynolds bio
9. Our Office — added assignment section
10. FAQs
11. Appointment CTA
12. Footer

## Images
The office images in `public/office-1.webp` and `public/office-2.webp` are the office images supplied for the assignment.

`public/maya-reynolds.png` is the supplied portrait used for the therapist profile.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

For production:

```bash
npm run build
npm start
```

## Notes
- The therapist and practice are fictional for the internship assignment.
- The office address is used exactly as supplied in the assignment profile.
- Appointment buttons currently point to the consultation section / email CTA; no booking backend is included because the assignment is a front-end practical.
